# NOAA-Tides-Android

Native Android app (Kotlin + Jetpack Compose) for viewing a week of NOAA CO-OPS tide predictions. Companion to the [NOAA-Tides web app](https://github.com/cs669/NOAA-Tides).

## Run

1. Open this folder in **Android Studio**.
2. Let Gradle sync, pick a device or emulator (API 26+), and click **Run**.
